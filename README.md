## Quick start

```bash
cd code
pip install -r requirements.txt
./run_all.sh                          # recomputes data/ and ../paper/figures/
cd ../paper
pdflatex twin_rigidity.tex && pdflatex twin_rigidity.tex
```

Tested with Python 3.13, NumPy 2.5 and Matplotlib 3.11 on Linux: a clean rerun of `run_all.sh` took 11 min 38 s and reproduced every value in `data/` exactly. Peak memory is about 4 GB.

`data/twin_swing_slim.npz` holds the race curves used for Figure 1. The full `twin_swing.npz` (45 MB) also holds
every window array. It is regenerated by `twin_swing.py` and is not included, to keep the archive small.

## Status of the results

The manuscript separates these levels, and so should any summary of it:

- **Proved (unconditional):** Theorem 1.1, that the double-coincidence part of T4 is −(S2/4) log²H + O(log H).
  Also Lemmas 4.1–4.4, Proposition 4.5 (the prime analogue, −½ log H) and the pairing Lemma 5.1.
- **Outlined proof:** Proposition 6.1, the spectral lower bound T4(H) ≥ −(S2/4) log²H − O(log H log log H).
  Every step has been checked but not every estimate is written out.
- **Hypothesis:** Hypothesis 6.2, a bound on the low-frequency spectral mass. It would give the matching upper bound.
  The data satisfy it with a wide margin.
- **Conditional on Hardy–Littlewood:** the link between T4 and the window variance of the twin race, equation (4).
- **Conjectures:** the quadratic rigidity law (Conjecture 1.2) and the vanishing bias (Conjecture 7.1).
- **Numerical:** everything in Tables 1–3 and Figures 1–5, computed to 10^10 (race) and 10^8 (singular series).
